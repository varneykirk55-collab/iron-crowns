# Assets: env/savanna

All meshes here are **procedural and original**. They are generated by `pipeline/blender/env_savanna.py` using Blender bmesh with vertex colours only: no textures, no downloads. The script reuses the helpers in `pipeline/blender/env_nordic.py` and the shared foliage and ground shaders. The only Nordic model reused is `env_reeds` (shores). There are no third-party or CC assets, and the licence is the same as the repository's.

| model | tris | what |
|---|---|---|
| env_umbrella_a / _b | 300 / 300 | umbrella thorn (Vachellia tortilis type): short forked trunk, very flat wide crown |
| env_baobab | 400 | baobab: swollen bottle trunk, stubby branches, sparse leaf clumps |
| env_miombo_a / _b | 248 / 248 | miombo / dry-deciduous tree (Brachystegia; also the teak / sal stand-in on the Deccan and the cerrado tree in the campos) |
| env_euphorbia | 328 | candelabra euphorbia: ribbed, upcurving succulent branches |
| env_thornbush | 140 | low thorn scrub / sickle-bush clump |
| env_sav_grass | 12 | tall savanna bunchgrass card (red oat / thatching grass) |
| env_termite_a / _b | 120 / 120 | laterite termite mounds with chimney spires |
| env_kopje_a / _b | 80 / 80 | rounded exfoliating granite boulders |
| env_kopje | 720 | kopje / inselberg: stacked granite boulders on a low dome (outcrop) |
| env_sav_far | 32 | distance LOD for bushveld / woodland belts |
| env_reeds | 14 | merged Nordic reeds (shores) |

No shader changes: savanna uses only the existing biome profile fields (palette, tints, look, mats).
