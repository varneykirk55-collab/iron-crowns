# Assets: env/scandinavia-medieval

All new environment assets are **original and procedural**. They are generated by code in this repo. There are no third-party files, no downloaded textures, no photo scans and no AI-generated images inside the game. Their licence is the project's own (the same as the rest of the code), and they can be released as CC0 if Kirk wants. No attribution is required.

| Asset(s) | Source | How made |
|---|---|---|
| `game/assets/models/env_spruce_a/b/c.glb`, `env_pine_a.glb`, `env_birch_a/b.glb`, `env_conifer_far.glb` | `pipeline/blender/env_nordic.py` | Blender bmesh script: tiered cones and crowns, with vertex colours and a foliage flag in UV2.y. `env_conifer_far` is the low-poly LOD/far-belt tree. |
| `env_boulder_a/b/c.glb`, `env_outcrop_a.glb`, `env_pebbles.glb` | same script | Subdivided, noise-displaced and flattened icospheres with lichen/granite vertex colours. |
| `env_grass_tuft.glb`, `env_grass_dry.glb`, `env_heather.glb`, `env_juniper.glb`, `env_reeds.glb`, `env_log.glb` | same script | Procedural blades and cards, plus a cylinder log. |
| `game/shaders/battle_terrain.gdshader`, `env_foliage.gdshader`, `env_water.gdshader` | hand-written | All variation comes from Godot `FastNoiseLite`/`NoiseTexture2D` at runtime. There are no image textures. |
| Terrain masks and noise | `battle_environment.gd` | Baked at runtime from the battle seed and the province data. |

Rebuild the models with `blender -b --python pipeline/blender/env_nordic.py [-- name ...]` (it writes `game/assets/models/env_*.glb` only).
Three variants are generated but not placed yet (kept as spares): `env_spruce_c`, `env_birch_b`, `env_grass_dry`.
