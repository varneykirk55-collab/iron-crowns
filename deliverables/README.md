# Iron Crowns: real-time grand strategy (vertical slice)

This is an original 3D real-time grand strategy prototype made in **Godot 4.7 (GDScript)**. The 3D assets are generated by **headless Blender Python scripts**.

You play a country, not individual soldiers. You raise and equip armies, order them across a 3D world map with real coastlines, and handle diplomacy and the economy. Wars are fought as fully AI-simulated 3D battles. You only choose the formation and the objective.

* Playable nations: **United States, Sweden, Japan**. The other 186 countries are AI-run.
* Map data: 641 provinces and 346 sea zones built from Natural Earth (public domain).
* Global eras: Medieval (1300), Pike & Shot (1500), Age of Revolutions (1800), Mechanised War (1914), Modern (1980). Eras advance with the calendar. There are no research trees.

## Launching

### Prebuilt (no Godot needed)
* **Linux x86_64:** `cd build/linux && ./GrandStrategy.x86_64`. Keep `GrandStrategy.pck` next to the binary.
* **Windows x86_64:** run `build/windows/GrandStrategy.exe` with `GrandStrategy.pck` in the same folder. This build was exported but has **not been run on Windows**.

### From source
1. Install Godot **4.7.x** (standard build, not .NET).
2. Open `game/project.godot`, or run `godot --path game`.
3. On the first open, Godot imports the `.glb` assets. This takes about 1 minute.

The renderer is GL Compatibility, so it runs on integrated GPUs and on software rendering. All development and testing used Mesa llvmpipe, a software renderer.

## How to play
1. **Main menu:** pick a start year (era), then pick a nation.
2. **Campaign map:** the game runs in real time. Press Space to pause and 1–5 to set the speed.
   * **Left-click a province** to see the owner, terrain, resource, population and garrison. In your own provinces, the panel has buttons to **raise regiments instantly** (current-era equipment only).
   * **Left-click an army** to see its regiments and status. **Right-click a province** to march the selected army there. Routes are computed automatically and can include naval transport.
   * **F1 Diplomacy:** relations, trade agreements, alliances, non-aggression pacts and war declarations with AI nations. AI nations also propose deals to you.
   * **F2 Economy & Army:** income and expenses, upkeep, resources and needs, administration, procurement, and refitting old-era armies.
3. **Battles:** when one of your armies meets an enemy army, a deployment window opens. Choose a formation and an objective, then either **watch** the battle in 3D or let it auto-resolve. In both cases the same deterministic battle simulation decides the outcome. While you watch, the world keeps running in the background. Press **Leave** to go back to the map. Leaving mid-battle lets the battle finish off-screen with the same simulation.
4. **Era change:** when the calendar reaches the next era's start year, every nation enters the new era. Existing armies keep their old equipment until refitted. Procurement offers only the new era's units.

## Developer commands
Run these from the repo root (`tools/godot` is the Godot 4.7.2 binary used for development):
```
godot --headless --path game res://tests/test_runner.tscn        # 61 gameplay/sim tests -> test_results.txt
xvfb-run -a godot --path game -- --demo=campaign --nation=USA     # scripted demo + screenshots -> shots/
                                 --demo=battle --nation=USA --reinforce=1 [--closeup]
                                 --demo=diplomacy --nation=SWE
                                 --demo=era --nation=JPN
                                 --demo=menu
```
Add `--write-movie /abs/path/out.avi --fixed-fps 30` to record a video. Note that `--reinforce=1` is a **demo-only scenario setup**: it gives the defender a field army on the invasion route so that a large battle happens quickly.

## Asset pipeline
* `pipeline/build_map.py` and `pipeline/make_gamedata.py` turn the Natural Earth data into a province-id raster, a height map, adjacency, and nation and unit JSON.
* `pipeline/blender/*.py` build every model in Blender procedurally: soldiers and cavalry for 5 eras, rigged with baked vertex-animation textures; artillery, buildings, trees, map markers and banners. They write the `.blend` files to `blend/` and the `.glb` files to `game/assets/models/`. Example: `blender -b --python pipeline/blender/<script>.py`.
* The battle crowds are drawn with MultiMesh instancing, a VAT shader and 2 LOD levels.

All art, names and content are original or public-domain geodata. No third-party game assets are used.
